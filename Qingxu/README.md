# 青序 · C# 原生版

当前主力版本，运行时不启动 Python、Node 或命令行脚本，发布为自包含单文件。

## 与旧版的关系

- 原生版默认优先读取工作区根目录的 `计划.xlsx`，兼容原 `outputs/study-plan/计划.xlsx`，也可通过 `--book` 指定位置。移动工作簿时需一起移动其 `.qingxu.json` 等本地状态文件。
- 本地队列：本版用 `.qingxu.json`，旧版用 `.agenda.json`；首次启动会把旧版未同步的修改导入过来。
- PowerShell 旧版已封存；当前功能和修复以本原生版为准。保留单实例锁、版本和 SHA-256 校验、备份及原子替换。

## 本版额外能力

- 顶部完成进度、底部快速添加框
- **日程是一条时间流**：课程（固定）和自己的安排按时间混排在同一条竖轴上，左边时间轴、右边色条区分课程／任务；没有安排的空档压成一行「空 1 小时 30 分」，不占版面，也不会显示空刻度。**6:00 到第一件事、最后一件事到 24:00 也是可拖放的时段**，早上和晚上都能落到具体时刻，不会只剩「排到最后」。整天没有安排时只剩「日程」标题和一条拖进来才展开的投放带。
- **拖到哪一刻就排到哪一刻**：把待办拖到空档上，空档会展开成 30 分钟刻度的尺子并显示落点时间；松手就按该时刻排期。落在已有条目上会把它和后面的任务往后推；推不动 24:00 时改放最近空档。整条任务都能按住拖（右侧按钮和底边调整时长的手柄除外），单击仍然只是勾选；拖到滚动区上下边缘会自动滚动，日程再长也能一路拖到晚上。
- **拖到课程上就是课内任务**：把待办拖进课程条目的「课内任务」格子，写进「课内安排」的课内任务列，原待办不再单独占一条。格子平时不写提示文字，拖动时才会展开提示。「···」里把课内任务清空并保存，就能删掉以前设过的课内任务。
- **行内撤销**：日程条右侧的 `↺` 取消这条的时间排期并放回待办（拖到待办区不会再直接抹掉时间，只提示用 `↺`）；课内任务后面的 `↺` 把最近一次并进去的任务退回待办，并把课内任务还原。
- **插入即顺延**：拖到已有条目上时占住落点，后面的任务依次往后推；推到 24:00 还推不动，就改放当天最近的空档并在状态栏说明。
- **拉底边改时长**：按住日程卡片下沿上下拖，按 5 分钟一档调整，松手才写盘。
- **考试强调**：顶部列出三周内的期中／期末／小测（带「N 天后」）；当天撞上考试的课程或事项整条标红，并挂上具体考法角标。
- **容量提示**：流末显示「已排 X · 空档 Y」，排满 10 小时会提醒今天挺满。
- **自动排**：待办标题右侧的「自动排」把待办按顺序填进 08:00 之后的空档（每项 15 分钟起）。
- 独立“学期”页读取 Excel“学期总清单”，状态与顺序贯穿整个学期，可编辑、勾选、标记未完成、强调、删除和拖动排序；「···」里可设置计划完成日期，到期当天会出现在日程待办中。
- “同步 Excel”后台更新工作簿，不启动 Excel；冲突窗口支持全选和取消全选。托盘菜单提供独立的“打开 Excel”。
- 键盘快捷键：`←` `→` 翻日期、`T` 回今天、`N` 新建、`R` 重读、`1`–`5` 切页、`Esc` 关弹层
- 右键「复制到明天」
- 勾选/高亮只重绘当前卡片，不重建整棵控件树
- `--page N` 直接打开指定页，`--smoke-test <json>` 截图并采样内存/CPU（仅用于副本）

## 构建

```powershell
Qingxu/build.ps1 -Test     # 构建并运行原生回归检查（需要本地工作簿）
Qingxu/build.ps1 -Publish  # 自包含单文件 → outputs/native-win-x64/青序.exe
```

## 仓库与个人数据

原生版当前在私有 `study-planner` 仓库维护。公开 `qingxu` 仓库保留封存的 PowerShell 版本。个人 Excel、课表、本地状态、备份和日志不纳入新的代码提交。

## 注意

- 不要用 `XamlReader.Parse` 做 ControlTemplate：模板能解析、控件也占位，但 Border 不绘制，改用自绘控件树。
- 直接改 XLSX 包内单元格，保留其他压缩条目与样式；写入必须版本号 + SHA-256 双校验 → 备份 → 原子替换。
